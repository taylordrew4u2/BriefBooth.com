# BriefBooth walkthrough

A 30-second silent, captioned slideshow of actual application screens, captured October 19, 2026. This is an edited screenshot walkthrough, not a continuous recording.

| Time | Screen | What it demonstrates |
| --- | --- | --- |
| 00:00–00:05 | Homepage | One link connects intake, consultation options, and scheduling. |
| 00:05–00:10 | Client intake | One question at a time; optional answers reduce friction. |
| 00:10–00:15 | Consultation options | Clients choose the service and duration that fit their needs. |
| 00:15–00:20 | Scheduling | Meeting format, timezone, time selection, and a clear summary. |
| 00:20–00:25 | Demo completion | The demo confirms the flow without creating a real appointment. |
| 00:25–00:30 | Consultant studio | Approval and upcoming counts, navigation, and a shareable booking link. |

The demo uses Alex Morgan, a fictional consultant, and Jordan Lee / jordan@example.com, fictional client information. No email was sent and no meeting was created for this capture. The consultant studio shows the owner's public brand and an overview without client records or credentials.
