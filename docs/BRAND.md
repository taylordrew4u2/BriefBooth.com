# BriefBooth brand assets

The booth icon represents a space for a focused consultation: an open entrance, enclosing side panels, a canopy, and a seat. It replaces the original `b.` monogram.

## Assets

- [Blue booth SVG](../public/brand/booth.svg): primary mark on white or pale surfaces.
- [White booth SVG](../public/brand/booth-white.svg): reversed mark on charcoal or blue.
- [Browser icon](../app/icon.svg): the same geometry, packaged through Next.js metadata.
- [Phone home-screen icon](../app/apple-icon.png): 180px raster export on white.

The live header and footer render inline SVG using the same geometry. No external image service or icon subscription is required.

## Usage

Use the mark upright and preserve its proportions. Leave clear space around it; do not stretch, rotate, add gradients, or put details inside the doorway. At small sizes, use the symbol alone. In navigation, pair it with the existing BriefBooth wordmark and keep the accessible link name “BriefBooth home.”

The blue is `#137FEC`; neutrals are `#333333`, `#676767`, and `#B4B4B4`. Typography remains Instrument Sans. Marketing may use strong blue/charcoal blocks and oversized typography; booking forms should retain readable labels, visible focus states, and clear spacing.

The conceptual brand boards are design explorations. The committed SVG assets are the implementation source for the shipped identity. Third-party review submissions are separate assets and are not automatically changed by a website deployment.
